# Chirper – Laravel CRUD Application

A small Laravel application built to practise core PHP/Laravel development patterns including authentication, routing, controllers and CRUD operations.

## Features

- User registration and login
- Authenticated user sessions
- Create, edit and delete chirps
- Route protection with Laravel middleware
- Controller-based request handling
- Blade-based front-end views

## Technologies

- PHP
- Laravel
- Blade
- MySQL / SQLite
- HTML / CSS
- Git / GitHub

## What This Project Demonstrates

This project demonstrates practical use of Laravel routing, middleware and controllers to build an authenticated CRUD application.

Authenticated users can create, update and delete chirps, while guest users can register or log in.

## Key Routes

- `GET /` – view chirps
- `POST /chirps` – create a chirp
- `GET /chirps/{chirp}/edit` – edit a chirp
- `PUT /chirps/{chirp}` – update a chirp
- `DELETE /chirps/{chirp}` – delete a chirp
- `/register`, `/login`, `/logout` – authentication flows
